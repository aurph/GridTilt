### 1F. Core Web Vitals Optimization
 
Run a full performance audit and optimize for Google's Core Web Vitals:
 
**Largest Contentful Paint (LCP) — target under 2.5s:**
- Preload critical fonts
- Optimize the hero section to render without waiting for API data (show layout immediately, fill numbers when data arrives)
- If the Power Map uses heavy tile images, lazy-load them
- Add `priority` to the first meaningful image on each page
 
**First Input Delay / Interaction to Next Paint (INP) — target under 200ms:**
- Make sure filter clicks on the Power Map respond instantly (client-side filtering, no API calls for 48 facilities)
- Debounce any search inputs (Portfolio Overlay ticker search)
- Ensure hover effects use CSS transforms/opacity only (GPU-accelerated, no layout thrashing)
 
**Cumulative Layout Shift (CLS) — target under 0.1:**
- Set explicit width/height or aspect-ratio on all images and charts
- Reserve space for the news ticker, index cards, and sector pulse so they don't shift when data loads
- The skeleton/loading states must be the exact same dimensions as the loaded content
 
**Additional performance:**
- Enable gzip/brotli compression on all responses
- Set proper `Cache-Control` headers: static assets = 1 year, API responses = 5-15 minutes
- Implement `next/dynamic` for below-fold components (US Electricity Demand chart, Catalyst Calendar)
- Prefetch data for pages the user is likely to visit next (from Tilt Overview, prefetch The Stack data)
 
### 1G. Crawlability
 
- Make sure the app is fully server-side rendered (SSR) or statically generated (SSG) for all pages Google needs to crawl. If any pages are client-side only, convert them.
- All page content must be in the initial HTML response, not loaded via client-side JavaScript after hydration. Google crawls the initial HTML.
- Internal links between pages must be real `<a href>` tags, not JavaScript `onClick` navigation. The sidebar nav links must be crawlable anchor tags.
- Add breadcrumb navigation to sub-pages (stock pages, sector pages) with BreadcrumbList schema.
