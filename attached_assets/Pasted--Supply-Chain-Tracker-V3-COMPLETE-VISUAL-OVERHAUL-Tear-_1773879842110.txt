Tear out the current Supply Chain Tracker entirely. The vertical scrolling infographic layout does not work. Replace it with a structured, icon-rich, org-chart-style interactive web diagram that works on every resolution. Read this entire prompt before writing any code.

---

## THE CONCEPT

Think of this like an organizational chart for the energy systems powering AI.

At the top: one root node — **"AI Power Supply Chain"**

Below it: 5 main system branches — Raw Materials, Generation, Transmission, Distribution, End Use

Below each system: **sub-system clusters** — for example, Generation breaks into Nuclear, Gas Turbines, Solar, and SMRs. Each sub-system is its own visual cluster with an icon, a label, and a set of companies inside it.

The whole thing is a **tree/web that fits in one viewport**. No scrolling to see the full picture. The default view shows the top 2 levels (root → 5 systems → sub-system icons). Clicking a sub-system expands it to reveal companies and details.

## TECHNICAL APPROACH

Use a **CSS Grid + Flexbox tree layout**. NOT React Flow. NOT a canvas. NOT an SVG-only approach. Use standard HTML/CSS with SVG only for the connection lines between levels.

Why: CSS Grid gives you responsive control at every breakpoint. The current implementations keep breaking on different resolutions because canvas/React Flow don't adapt. A grid-based tree adapts naturally.

### Page Structure

```html
<div class="supply-chain-page">
  <!-- Summary bar at top -->
  <div class="sc-summary-bar">...</div>

  <!-- The tree diagram — fills remaining viewport -->
  <div class="sc-tree">
    <!-- Level 0: Root -->
    <div class="sc-root">AI Power Supply Chain</div>

    <!-- SVG connector lines (Level 0 → Level 1) -->
    <svg class="sc-connectors-L0">...</svg>

    <!-- Level 1: 5 System Nodes -->
    <div class="sc-systems-row">
      <div class="sc-system" id="raw-materials">...</div>
      <div class="sc-system" id="generation">...</div>
      <div class="sc-system" id="transmission">...</div>
      <div class="sc-system" id="distribution">...</div>
      <div class="sc-system" id="end-use">...</div>
    </div>

    <!-- SVG connector lines (Level 1 → Level 2) -->
    <svg class="sc-connectors-L1">...</svg>

    <!-- Level 2: Sub-system icons (always visible) -->

</div>
```

## CONNECTOR LINES

Thin SVG lines connecting:
1. Root → 5 system nodes (fan out from bottom-center of root to top-center of each system)
2. Each system node → its sub-system icons (fan out from bottom-center of system to top of each icon tile)

### Line styling:
```css
.connector-line {
  stroke: rgba(240, 120, 0, 0.2);
  stroke-width: 1.5;
  fill: none;
}
```

Use straight lines or very slight curves. Keep them subtle — they're structural, not decorative. The animated flowing dots from the previous version can stay on the Level 0→1 connectors (root to systems) but NOT on the Level 1→2 connectors (too busy).

### How to draw them:

Use an absolutely-positioned `<svg>` overlay that covers the tree area. On mount and on window resize, calculate the positions of each node/tile using `getBoundingClientRect()` and draw `<line>` or `<path>` elements between them.

```typescript
// Recalculate on: mount, resize, and when a subsystem expands/collapses
useEffect(() => {
  const updateLines = () => {
    // Get positions of all nodes
    // Draw SVG lines between parent → children
  };
  updateLines();
  window.addEventListener('resize', updateLines);
  return () => window.removeEventListener('resize', updateLines);
}, [expandedSubsystem]);
```

### What clicking does visually:
1. The clicked sub-system icon gets the `.active` state (colored border + background tint)
2. Its parent system node also gets `.active` state
3. All OTHER system nodes and sub-system icons dim to 40% opacity
4. The detail panel slides in below the tree
5. Connector lines from root → active system → active sub-system become brighter/thicker

### Clicking a different sub-system:
- Smoothly transitions: old panel fades out, dimming shifts, new panel slides in
- Clicking the same sub-system again closes the panel and removes all dimming

### Clicking the SYSTEM node itself (e.g., clicking "Generation" rather than "Nuclear"):
- Expands a summary panel showing ALL sub-systems in that stage as a grid, with aggregate stats
- Like clicking a department head in an org chart to see the whole department

## RESPONSIVE DESIGN — THIS MUST WORK EVERYWHERE

### Desktop (1280px+):
- Full tree visible in viewport: root → 5 systems → sub-system icon clusters
- 5 system nodes in one row, evenly spaced
- Sub-system icons in a row under each parent
- Detail panel appears below the tree when a sub-system is clicked

### Laptop (1024-1279px):
- Same layout, slightly more compact spacing
- System nodes may be 160px wide instead of 180px
- Sub-system icons 70px instead of 80px

### Tablet (768-1023px):
- System nodes wrap to 2 rows: 3 on top, 2 on bottom (centered)
- Sub-system icons stay grouped under their parent
- Connection lines recalculate
- Detail panel full width

### Mobile (< 768px):
- System nodes stack vertically in a single column, centered
- Sub-system icons display as a 3-across grid under each system
- Connection lines become simple vertical lines
- The tree becomes a collapsible accordion: tap a system to reveal its sub-system icons, tap a sub-system to see the detail panel
- This is the ONE layout where scrolling is acceptable

### THE KEY RULE:
Test at 1440px, 1280px, 1024px, 768px, and 375px. The tree must look intentional at every size. No overflow. No horizontal scroll on desktop. No overlapping nodes. If nodes would overlap, reduce font sizes and icon sizes before breaking the layout.

## ANIMATIONS

1. **Page load**: tree fades in level by level — root first (0ms), systems (200ms), sub-systems (400ms). Each level fades + slides up 10px. Total entrance: ~600ms.
2. **Hover on system node**: lift 3px, border glow in system color, 200ms
3. **Hover on sub-system icon**: scale 1.08, 150ms
4. **Click sub-system → detail panel**: slides down from 0 height, fades in, 350ms ease-out
5. **Dimming non-active nodes**: opacity transition to 0.4, 300ms
6. **Connection line pulse**: on the active path (root → system → sub-system), lines brighten and get a subtle pulse animation

## DO NOT

- Do NOT use React Flow or any canvas library — use CSS Grid + SVG lines
- Do NOT make the tree scrollable on desktop — it must fit in one viewport
- Do NOT hide the sub-system icons behind a click — they must be visible by default (the whole point is "many icons")
- Do NOT use blue anywhere — all accent colors are warm (orange, copper, gold, amber, red, green)
- Do NOT make the system nodes tiny — 180px wide minimum on desktop
- Do NOT skip the responsive breakpoints — test at every size
- Do NOT make the detail panel a modal/overlay — it pushes content down inline
- Do NOT show company stock cards in the default view — they appear only in the expanded detail panel
