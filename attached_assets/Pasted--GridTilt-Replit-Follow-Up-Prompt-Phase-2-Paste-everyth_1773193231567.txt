## 2. NEWS BANNER — MUST BE API-DRIVEN

The orange news ticker/banner should NOT be manually curated. It needs to pull from a real news API automatically. Here's how to implement it:

**Primary API: NewsData.io**
- Free tier: 200 credits/day (more than enough for a news ticker)
- Endpoint: `https://newsdata.io/api/1/latest`
- Query params: `q=data+center+OR+nuclear+energy+OR+power+grid+OR+AI+infrastructure&language=en&category=business,technology`
- Returns JSON with headline, source, link, published date
- Sign up at https://newsdata.io — free API key, no credit card

**Fallback API: NewsAPI.org**
- Free tier: 100 requests/day
- Endpoint: `https://newsapi.org/v2/everything`
- Query: `(data center OR nuclear power OR grid infrastructure OR AI infrastructure OR power grid OR utility earnings)`
- Domains filter: `reuters.com,utilitydive.com,datacenterdynamics.com,cnbc.com,bloomberg.com`

**Implementation:**
- Fetch news on server-side (API route `/api/news`) every 30 minutes. Cache the results. Do NOT call the API on every page load.
- Filter results to only show headlines relevant to: data centers, AI infrastructure, power grid, nuclear energy, utility companies, grid hardware, energy policy
- Store the last 20-30 headlines in a simple cache (Redis, in-memory, or even a JSON file that refreshes)
- The banner reads from this cache. If the cache is empty or stale (>2 hours), show nothing (don't show an empty banner)
- Each headline in the ticker: `[Source Name] Headline text • date` — clicking opens source URL in new tab
- Scrolls continuously, pauses on hover, dismissible per session

**Keyword filter list for relevance scoring** (use these to filter/rank API results):
```
data center, datacenter, hyperscaler, AI infrastructure, power grid,
nuclear energy, nuclear restart, uranium, grid stress, interconnection queue,
transformer shortage, GE Vernova, Vertiv, Eaton, Constellation Energy,
PJM, ERCOT, MISO, WECC, utility earnings, power demand, megawatt,
gigawatt, behind-the-meter, renewable energy data center, cooling system,
Quanta Services, NuScale, SMR, grid modernization, energy transition,
electricity demand, baseload power, capacity auction, power purchase agreement
```

Headlines that don't contain at least one of these keywords should be filtered out.

## 8. GENERAL UX REFINEMENTS BASED ON INITIAL OVERHAUL

A few things to tighten based on what I'm seeing:

- **Don't stay too far from the current aesthetic.** The dark theme, the orange accent, the data-dense feel — that's GridTilt's identity. The overhaul should enhance it, not drift toward a generic SaaS look. If anything, lean MORE into the terminal/Bloomberg feel, not away from it.
- **The dashboard should feel alive.** Numbers updating, news scrolling, sparklines moving. Static dashboards feel stale. Every time I open GridTilt, something should be different from yesterday.
- **Hover effects should feel responsive but not distracting.** Quick transitions (150-200ms). No bouncing, no dramatic scale changes. Just enough to confirm "yes, this is interactive."
- **Information hierarchy matters.** The most important number on any page should be the biggest and brightest. Secondary info should be clearly subordinate. Don't make everything the same visual weight.
